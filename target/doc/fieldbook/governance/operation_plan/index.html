Module operation_plan 

Source
Expand description

Typed operation plans.

A command never grants its pipeline by declaring one operation. A caller supplies an OperationPlan whose steps each bind one actor, one action, one full data object, one source scope and one side-effect boundary to a written grant reference. Every step is authorized independently and reauthorized at its own side-effect boundary. A plan is installed atomically: a later failing step leaves no earlier step authorized.
