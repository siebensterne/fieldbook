Expand description

Authorize one caller-supplied egress intent from the runtime rights file and install it into the shared gate with a refreshable authority.

Returns the authority handle so the owner can invalidate the grant during a session; the gate observes the change at its next checkpoint.

§Errors

Returns an error for every fail-closed authorization condition.
