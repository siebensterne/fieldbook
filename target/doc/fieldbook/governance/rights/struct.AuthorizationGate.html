Struct AuthorizationGate 

Source 
pub struct AuthorizationGate { /* private fields */ }
Expand description

Instance-scoped authorization state.

One gate holds many independent authorizations for different providers, source products, segments and operations. Nothing is installed by default: an empty gate denies every egress. The gate is cheaply cloneable so the same instance can be shared with transport layers while remaining independent of any other gate in the process.

pub fn install_batch( &self, installations: Vec<ProofInstallation>, ) -> Result<Vec<String>>

Install a whole plan atomically: either every proof becomes active or none does. All fallible work (validation, duplicate detection and audit commits) completes before any state is mutated, so a failure on a later step cannot leave an earlier step authorized. A rollback audit record is committed when a failure is detected after earlier grant records.

Returns the session ids in installation order.

§Errors

Returns the first fail-closed denial without installing any proof.
