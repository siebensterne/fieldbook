fieldbook::governance

Module modality 

Source
Expand description

Typed acquisition ports separated by source modality.

A historical file provider and a multicast exchange do not share one lifecycle. The shared contract here is kept minimal: identity via a manifest, health, and disconnect. Everything else is a typed port that a connector implements only for the modality it genuinely declares.

There is no dynamic plugin framework and no modality inference. A manifest must declare a capability before the matching port applies, and a connector must not receive credit for a capability it did not declare.
