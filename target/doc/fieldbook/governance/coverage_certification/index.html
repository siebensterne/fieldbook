Module coverage_certification 

Source
Expand description

Coverage certification for global sources, markets and instruments.

A coverage record discloses what a source provides. Missing data is never represented as a zero value or as full coverage.

Certification is not one ordinal ladder. Discovery, implementation, technical validation, rights, operations, history, quality and certification are separate dimensions, so a live feed without history, or a licensed dataset awaiting validation, cannot hide an unmet condition.
