Module egress_intent 

Source
Expand description

Caller-supplied egress intent and active authorization lifecycle types.

An EgressIntent is the actual request a caller wants to perform. It is supplied by the caller; the authorization gate never derives one from an installed proof. Every field is explicit and there is no wildcard default.

The lifecycle types in this module implement the proposed model in NDC-SEMANTIC-MODEL-V2-PROPOSED.md section 2.5: a rights-registry revision, an immutable grant snapshot identity, a short-lived lease with a declared maximum duration, an active session id, reauthorization checkpoints and fail-closed refresh. Revocation is not instantaneous: the maximum propagation time is the lease duration, because that is how long a previously granted session can continue before it must refresh its authority.
