Module ndc_stream 

Source
Expand description

Bounded streaming NDC v2 Profile 1 producer with a two-intent lifecycle.

This module consumes one canonical record at a time from an ArtifactRecordSource. The core owns the record buffer: each adapter writes record bytes into a bounded RecordSink that the core supplies, and canonical JSON is validated only from those core-held bytes. Byte-derived order, expanded and stored digests are updated incrementally as bytes are emitted, and artifacts are written to an owned staging tree. No whole-artifact vector, whole-input record vector or whole-dataset sort exists on this path.

A durable PreparationIntent is written and synced before any source is consumed. A SealedPublicationIntent is written and synced only after every artifact reached end of stream, every staged file is synced and the manifest and sidecar exist. No receipt, marker or final rename precedes the seal. The existing publication core performs the final rename, receipt, marker and recovery; this module adds no second publication state machine.

Numeric maxima are DEFERRED by WS-STREAM-001. Production invocation requires an approved profile selected by trusted local policy, and no approved profile is registered. Only finite TEST_ONLY profiles admitted by a test harness can drive this path today. PERF-001 and OPERATIONALLY_QUALIFIED remain blocked.
