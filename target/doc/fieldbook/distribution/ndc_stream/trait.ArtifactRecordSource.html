Expand description

Bounded, one-record-at-a-time source for one planned artifact.

The core owns the record buffer. An adapter writes bytes into the RecordSink supplied by the core instead of returning a pre-materialized record. RecordSliceSource adapts already-materialized bytes, but it does not bound allocation that a caller performed before the write.

fn write_next_record( &mut self, sink: &mut RecordSink<'_>, ) -> Result<bool, StreamError>

Write one canonical record, without a line terminator, into the core-provided sink. Return true when a record was written and false at end of stream. A call after end of stream is a typed state error.
