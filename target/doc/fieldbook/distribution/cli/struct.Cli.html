Fields§

§config: Option<PathBuf>

TOML configuration file. Built-in defaults, file, environment, then CLI flags are applied in that order.

§rights_file: Option<PathBuf>

Runtime authorization records (TOML). Overrides [governance].rights_file.

§rights_audit_dir: Option<PathBuf>

Directory for machine-readable authorization decision events. Overrides [governance].audit_dir.

§egress_intent_file: Option<PathBuf>

Versioned TOML file declaring the caller’s actual egress intent. This is the request evaluated against the rights file, not a grant.

§operation_plan_file: Option<PathBuf>

Versioned TOML file declaring every operation step the command may perform. The full plan is authorized before startup; one declared step never implies another. Overrides [governance].operation_plan_file.

§no_tcp_nodelay: bool

Disable TCP_NODELAY on websocket sockets.

§source_ip: Option<IpAddr>

Bind websocket connections to this local IP address.

§source_port: Option<u16>

Bind websocket connections to this local source port. The value is a base: each connection binds base + shard * 256 + replica.

§connect_race: Option<usize>

Race this many simultaneous websocket handshakes and keep the first.

§output: Option<String>

Output file, or - for binary stdout.

§chunk_size: Option<usize>

Aligned output chunk size. Defaults to 64 MiB, matching the template AlignedSbeReader. Must be a power of two of at least 1024 bytes.

§overwrite: bool

Replace existing capture, sidecar, catalog, manifest, and segment files. Without this flag any existing artifact is a startup error.

§rotate_bytes: Option<u64>

Rotate the capture after this many bytes. Zero disables size rotation.

§rotate_secs: Option<u64>

Rotate the capture after this many seconds. Zero disables time rotation.

§min_free_bytes: Option<u64>

Stop before free space on the output filesystem drops below this many bytes. Zero disables the watermark.

§fsync_interval_secs: Option<u64>

Fsync the active capture or segment at this cadence. Zero syncs only on rotation and shutdown.

§catalog: Option<PathBuf>

Most recent accepted catalog checkpoint.

§catalog_mode: Option<CatalogMode>

Catalog bootstrap policy.

§catalog_max_age_secs: Option<u64>

Maximum accepted checkpoint age for warm and require modes.

§connect_concurrency: Option<usize>

Maximum simultaneous websocket connection attempts.

§shards: Option<usize>§replicas: Option<usize>§lifecycle_replicas: Option<usize>

Dedicated market-lifecycle control-plane sockets. Book shards never carry lifecycle subscriptions.

§metrics_listen: Option<SocketAddr>§metadata: Option<PathBuf>§report: Option<PathBuf>§journal_dir: Option<PathBuf>

Root directory for the raw-frame journal. Omit to disable recording.

§snapshot_interval_secs: Option<u64>§discovery_interval_secs: Option<u64>§max_markets: Option<usize>

Optional discovered-symbol cap. Zero means no cap.

§duration_secs: Option<u64>

Optional live-run duration. Zero means run until SIGINT/SIGTERM.

§log_json: bool

Emit structured JSON logs to stderr.

§command: Option<Command>
