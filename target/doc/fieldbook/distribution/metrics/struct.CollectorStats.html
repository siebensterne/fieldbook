Core-ingress boundary: LevelChange events admitted to the core.

Transport boundary: raw data frames read by the session workers. Derived from per-source worker status at metrics refresh time.

Adapter decode boundary: LevelChange events decoded by adapters.

§deltas_no_active_source: u64

Terminal dispositions of decoded deltas that are not already covered by deltas_emitted, deltas_rejected or suppressed_replica_duplicates.

§deltas_unknown_symbol: u64§deltas_non_live: u64§deltas_unassigned_source: u64§deltas_invalid_book: u64§deltas_shadow_clock_regression: u64§deltas_zero_noop: u64§deltas_sbe_conversion_failed: u64§rejected_recovery_snapshots: u64

Clockless recovery snapshots rejected because they preceded the acknowledged recovery fence or arrived without an active generation.

§sequence_resets: u64§clock_resets: u64

Exchange-clock decreases observed on an active book. These are expected across exchange maintenance and start a new comparison epoch.

§source_switches: u64§stale_probes: u64§stale_failovers: u64§crossed_snapshots_skipped: u64§duplicate_events: u64§suppressed_replica_duplicates: u64

Delta events delivered to a non-active replica: applied to that replica’s private book but not emitted. This is a transport duplicate, distinct from a duplicate application.

§lifecycle_events: u64§lifecycle_duplicates: u64

Duplicate events (same market, kind and exchange timestamp) skipped by the lifecycle deduplication barrier. Non-zero is expected when lifecycle_replicas > 1.

§lifecycle_unknown_symbols: u64

Lifecycle events whose market is not (or no longer) tracked. Unknown Create/Activate events additionally request an out-of-cycle REST reconciliation; never silently dropped.

§lifecycle_stale_dropped: u64

Lifecycle events whose exchange order is older than the order already applied for the same market (out-of-order replica delivery). Terminal notifications are never dropped; only nonterminal backfills.

§lifecycle_discovery_vetoes: u64

Discovery rounds that refused to re-add a market already known to be terminal (lifecycle tombstone newer than the round start). The round completes; the market is not resurrected.

§lifecycle_kept_metadata: u64

Discovery metadata conflicts resolved in favor of lifecycle-applied state for rounds that started before the lifecycle event applied.

§current_symbols: u64§shard_count: u64§discontinuity_incidents: u64

Discontinuity incidents detected (gaps in event continuity)

§unquantifiable_gaps: u64

Discontinuity incidents where the gap interval is unquantifiable (no sequence/clock)

§resyncing_symbols: u64

Symbols currently in Resyncing continuity state

§stale_symbols: u64

Symbols currently in Stale continuity state
