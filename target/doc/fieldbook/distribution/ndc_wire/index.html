Module ndc_wire 

Source
Expand description

Explicit producer mapping from internal release values to the ratified canonical NDC v2 Profile 1 wire representation.

The canonical schema package under workspace authority WS-NDC-2026-11-24-003 is the wire authority. The internal ReleaseManifest and its section types are inputs only: every wire member below is named and validated by this module, never inherited from a Rust field name. The internal pre-ratification sections carry opaque references and omit several required canonical members; a strict abstract evidence supplement supplies the typed values that the internal types do not hold. A missing, unknown, duplicated or coerced value fails closed with a typed WireError.

The critical correctness boundary is byte-derived record ordering. sort_byte_derived parses the canonical record bytes, extracts the ordering member, validates it against the artifact profile, derives the key and sorts. CanonicalRecord carries bytes only, so no caller can express a second position on the public producer input. The same validated input bytes are returned in sorted order; no record is re-serialized to obtain an ordering position.

Non-claim: this module is a producer-side mapping and conformance vector support. It creates no release, no right, no dataset acceptance and no cross-execution status. The signing seed used by the conformance executable is a published test vector, not a production key.
