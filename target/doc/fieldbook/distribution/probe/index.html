Module probe 

Source
Expand description

network-probe: a transport diagnostic for the collector’s egress path.

The probe never authenticates to a venue and never collects market data. It exercises exactly one real stage sequence — DNS, TCP, optional proxy negotiation, TLS and the websocket upgrade — and reports them separately, so “connected” cannot be mistaken for “a feed session is healthy”.

Result levels (see ADR 0002): the probe implements levels 0–2 (config parses, route is usable, TLS validates and the upgrade completes). Levels 3–4 require a venue-approved session, live subscription, capture, journal verification and deterministic replay, which are out of scope here.

Credentials never appear in the report. The venue URL is operator input; proxy credentials are read from the environment and are not printed, logged, or hashed.
