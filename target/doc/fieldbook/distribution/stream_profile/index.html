Module stream_profile 

Source
Expand description

Immutable, versioned resource-profile contract for the streaming producer.

The ratified contract in WS-STREAM-001 fixes the form of the profile and leaves every numeric maximum DEFERRED. This module therefore registers no production profile and no approved digest. Only finite profiles whose name carries the TEST_ONLY marker exist here, and they are reachable from a test harness alone.

All fields are private and are populated by one validating constructor. There is no setter, no caller-supplied raw limit on a production path and no fallback when trusted local policy cannot select an approved profile.
