Expand description

Run a live collection until the supplied future resolves.

shutdown returns the human-readable shutdown reason recorded in the run report. This is the same loop used by run; separating the trigger keeps the live orchestration testable without relying on process signals or a fixed wall-clock duration. collector.duration_secs is interpreted by run, not by this function.
