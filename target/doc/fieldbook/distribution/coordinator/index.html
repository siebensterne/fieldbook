Module coordinator 

Source
Expand description

Live collector coordinator.

One serialized writer owns the SBE file. Every websocket source is a worker task supervised by crate::session::run_worker; this module feeds decoded events into the synchronous CollectorCore, dispatches subscription and recovery controls, runs discovery, schedules periodic snapshots, and handles graceful shutdown.

Constants§

LIFECYCLE_SHARD
Shard identifier reserved for a dedicated market-lifecycle control plane. Book shards are validated to <= 256, so u16::MAX never collides with a book source. Exported for the report’s source list; consumers should use source.shard == LIFECYCLE_SHARD to distinguish the control plane.
