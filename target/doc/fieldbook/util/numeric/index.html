Module numeric 

Source
Expand description

Exact conversion between instrument-scale numeric values and the supplied challenge SBE representation.

The wire schema is fixed at six decimal places. Instrument metadata may use another scale, including more than six decimals. Conversion is exact and fails rather than rounding, so a value that cannot be represented in the capture is rejected before it reaches the writer.
