pub fn symbol_with<E, F>( self, exact_len: usize, f: F, ) -> Result<PriceLevelUpdateComplete<'a, H>, E>
where E: From<EncodeError>, F: FnOnce(&mut [u8]) -> Result<(), E>,

Lend exactly exact_len bytes of the var-data region to a closure for nested-message encoding. Zero-copy: the closure writes directly into the outer buffer.

Canonical nested-SBE pattern (AppMessage → L2Book):

let inner_len = InnerEncoder::compute_length_with_header(...);
after.payload_with(inner_len, |payload| {
    let len = InnerEncoder::wrap_and_apply_header(payload, 0)?
        .field(value)
        // continue the single encoder chain through all tail stages
        .encoded_length_with_header();
    debug_assert_eq!(len, inner_len);
    Ok(())
})?;

Returns the next stage on success; on failure the caller error propagates unchanged and no partial data is published.
