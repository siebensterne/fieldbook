fn visit_unknown( &mut self, header: &MessageHeader, frame: &[u8], ) -> Self::Output

Called for unknown template IDs (not in this schema).

header is the parsed schema-declared MessageHeader. frame is the complete frame — message header followed by the unparsed body — not the body alone. Must be implemented; there is no panicking default, because an unknown template is application policy rather than a crash.
