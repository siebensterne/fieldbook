Target-side contract. Implementing this trait is the only requirement for plugging a new destination into the runner.

Source

fn deliver(&mut self, request: &DeliveryRequest) -> DeliveryReceipt

Deliver one batch and report its outcome. Implementations must be safe to call again with the same idempotency key.

Provided Methods§

Source

fn deliver_batch(&mut self, batch: &DeliveryBatch) -> Vec<DeliveryReceipt>

Deliver an ordered batch. The default degrades to one single-event delivery per member, so connectors that cannot commit atomically stay correct. Real durable targets override this with one transaction.

Source

fn is_simulation_safe(&self) -> bool

Whether calling deliver is guaranteed to have no external side effect. Only side-effect-free connectors (for example the replay connector) override this; the runner uses it to avoid calling a real target in a simulated mode.

Dyn Compatibility§
