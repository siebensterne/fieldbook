Module durable_segmented 

Source
Expand description

Segmented, checkpointed local durability (Platform P6.2.1).

The production-shaped runner reaches this store through the crate::application::DurableStore abstraction. Segments hold multiple framed commits, are bounded by record count and encoded bytes, rotate into a verified archive, and are finalized with separate record, footer, rename and directory sync boundaries. See docs/segmented-durability-design.md.
