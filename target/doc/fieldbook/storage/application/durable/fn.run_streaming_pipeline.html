Expand description

Run a bounded streaming source into a target with a durable local store.

The anchor must already have been verified against the source identity and target. Every terminal outcome is committed to the store as one atomic record before the in-memory checkpoint is advanced. The runner stops at the first unresolved delivery or failed local commit, so a later source position can never leap over an unaccounted record. Callers wanting a simulated run should use run_jsonl_to_target_with_mode with a side-effect-free connector instead of this store-backed runner.
