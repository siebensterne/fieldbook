Run a pull-based streaming source with bounded, ordered batch delivery.

Unlike run_streaming_pipeline, this accumulates up to limits.max_events records (and limits.max_bytes encoded bytes) into one DeliveryBatch, delivers them in one target transaction and commits one checksummed local record. It flushes a pending batch before quarantining a malformed record and halts at the first unresolved transaction or failed local append.
