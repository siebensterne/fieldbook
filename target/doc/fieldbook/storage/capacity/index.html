Module capacity 

Source
Expand description

Startup capacity planning for one discovered universe.

The plan is computed before any source worker starts. It converts the selected venue records and outcome symbols into the resources the run will use and rejects a configuration that exceeds a declared ceiling. The estimates are conservative fixed costs, recorded in the current-state scope record; they are planning bounds, not a substitute for the measured scale runs.
