Module instrument_terms 

Source
Expand description

Family-typed instrument terms and unit-bearing exact measures.

Every numeric term carries a Unit and a decimal scale. Integer coefficients use i128 intermediates and checked arithmetic; no floating point type appears in this module. A bare number cannot cross this contract: ExactMeasure binds coefficient, scale and unit in one value.

The seven term families are separate payload structs behind the tagged InstrumentTerms enum. DerivativeKind is a validated projection of InstrumentKind, not a competing classification enum. Contract families and instances add dated-instance structure on top of that shared vocabulary. Identity comes from ObjectId values derived from immutable assertions; ticker and symbol text is not an identity input.

Revisions are append-only BitemporalAssertion records in a BitemporalLedger. The registry validates each payload before storage, rejects repeated subject and revision pairs, and answers historical queries with explicit valid and knowledge times. No clock, venue, feed, dataset, entitlement or order event is consulted.
