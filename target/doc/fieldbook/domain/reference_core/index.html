Module reference_core 

Source
Expand description

Canonical financial object identity, assertions and coverage.

This module declares abstract reference-object types. It names no venue, dataset, provider or rights decision and reads no present-day clock. Identities derive from explicit immutable assertions. Every lookup reports uncertainty instead of selecting a first candidate.
