Module canonical 

Source
Expand description

Canonical event envelope and normalized event taxonomy (Platform M4, Phase 1).

This module adds canonical event types without changing crate::model::ExchangeEvent. The legacy type remains the market-specific collector/SBE/replay wire contract and is not changed here. Nothing in this module alters the SBE writer, raw-frame journal, replay JSONL, or catalog checksums. No dependency is added, and no database, connector or durable storage is implemented.

The taxonomy separates event kinds that the legacy wire contract conflates or omits. A snapshot is a full book anchor; a delta is a single level change; a trade is a trade; a best-bid-offer is a top-of-book quote and is never an L2 book; telemetry/assets are asset context and never a book delta. There is no From conversion that manufactures a trade, BBO, asset-context or gap event from a non-trade ExchangeEvent.

Every envelope carries provenance: an opaque deterministic EventId, the source/feed identity, the connection epoch, optional sequence metadata, source and receive times, and an optional raw observation reference. The raw journal remains the independent source of truth; a canonical envelope only points back to it. CanonicalReader fails closed on an unsupported CANONICAL_SCHEMA_VERSION or on missing provenance.

NormalizedStore is a contract, not a new storage subsystem. The only implementation here is InMemoryNormalizedStore, used for tests.

Structs§

AppendReceipt
Receipt returned for one accepted append.
AssetContext
Asset or venue-wide context (for example venue statistics or fastAssetCtxs). Telemetry and asset records are context, never a book anchor, book delta or trade.
BestBidOffer
Top-of-book best bid and best offer. This is a quote projection, not an L2 book: it carries at most one level per side and is never a BookSnapshot or BookDelta.
BookDelta
One level change. Only an ExchangeEvent::LevelChange maps here.
BookSnapshot
A full two-sided book anchor. Only an ExchangeEvent::Snapshot maps here.
CanonicalEnvelope
Generic canonical envelope. T is one payload from the taxonomy or the CanonicalEvent sum type. Provenance and schema version are invariants a reader enforces, not optional hints.
CanonicalLevel
One canonical price level, expressed as raw i64 coefficients. Scale and unit stay in instrument metadata; no floating point is introduced.
CanonicalPriceRange
Exact price band carried by a lifecycle update.
CanonicalReader
Decodes and validates canonical envelopes. This is a reader contract only: it neither writes the raw journal nor projects the SBE output.
EventId
Opaque, deterministic identity of one canonical event. It is derived from explicit provenance inputs, never from a wall clock or a display label.
InMemoryNormalizedStore
Test-only in-memory normalized store. It is not durable, not concurrent, and not a production storage subsystem.
InstrumentLifecycle
Instrument reference-data lifecycle notification. Only an ExchangeEvent::Lifecycle maps here.
NormalizationContext
Explicit inputs that the legacy wire event does not carry: identities, provenance pointer and the derivation namespace/authority. Passing them explicitly prevents identity from being guessed from a mutable title or from an unresolvable display symbol.
SequenceMetadata
Ordering metadata carried by an event. Receive order is local and independent of any venue sequence or exchange clock.
StreamGap
An observed sequence gap. It is never derived from StreamReset: a reset is a deliberate invalidation, a gap is an unexplained missing frame.
StreamReset
Invalidated symbols awaiting fresh snapshots. Only an ExchangeEvent::StreamReset maps here.
Trade
An executed trade. There is no From<&ExchangeEvent> for this type: only an explicit trade observation may construct it. In particular a level change, telemetry record or asset context is never a trade.

Enums§

CanonicalChange
Absolute replacement or signed adjustment of one level. An absolute change and a delta change have distinct meanings.
CanonicalError
Errors from the canonical reader/store boundary. Both are fail-closed: an envelope that cannot be trusted is never admitted.
CanonicalEvent
The typed canonical taxonomy. Every variant is a distinct event kind with no silent coercion between them.
CanonicalKind
Stable discriminant of a canonical event kind. These strings are part of the serialized contract.

Constants§

CANONICAL_SCHEMA_VERSION
Version of the canonical envelope schema. Envelopes serialize with this value; readers reject any other value.

Traits§

NormalizedStore
Conceptual normalized durability contract. No durable implementation exists in Phase 1: the raw-frame journal remains the independent record and the in-memory store below exists for tests only. Implementations must preserve raw provenance; appending an invalid envelope is rejected.
