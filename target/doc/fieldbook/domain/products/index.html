Source
Expand description

Typed data-product and source-capability contracts (Platform M3, Phase 1).

These contracts coexist with MarketDataSession::apply_subscriptions still takes &BTreeSet<String>, and ExchangeCapabilities::new(bool) still reports the legacy sequence-clock flag. Nothing here changes the SBE, journal, replay or catalog formats, and no adapter behavior is altered.

A DataProduct names what a source can deliver. A ProductKind is its stable discriminant and supplies deterministic subscription keys so a legacy native-symbol set can be converted to a SubscriptionSet without migrating MarketInfo.symbol or native_symbol. A SourceCapabilities declaration describes how a source delivers those products. A SubscriptionLease tracks the local lifecycle of one subscription and refuses to treat a socket write or a stale connection epoch as a venue acknowledgement.
