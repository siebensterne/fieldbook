fieldbook::domain

Module information 

Source
Expand description

Domain-specific structures for institutional financial information.

A release is not a trade and a filing is not an instrument. These payloads carry domain meaning in their own structures behind the shared UniversalEnvelope. They are versioned independently of market-data payloads, and every record keeps both valid time and transaction time so corrections and revisions remain queryable.
