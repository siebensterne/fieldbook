Module identity 

Source
Expand description

Persistent instrument and reference identity (Platform M2, ADR-0001).

These identity types are additive. MarketInfo.native_symbol and MarketInfo.symbol remain the bounded migration seam and the only bridge to the SBE wire format. Nothing here changes journal, replay, catalog checksums or collector behavior.

Every identity is an opaque, platform-assigned newtype derived from an explicit immutable assertion (namespace, assigning authority, stable wire key). Titles, slugs and display labels are never identity inputs.
