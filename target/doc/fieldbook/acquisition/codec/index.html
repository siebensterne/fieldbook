fieldbook::acquisition

Module codec 

Source
Expand description

Acquisition feed decoding primitives.

A CodecRegistry maps a (source, schema_version) pair to a boxed FeedCodec and partitions decoded observations by outcome. Decoding is fail-closed: a packet without a registered codec produces an error rather than a partial batch.
