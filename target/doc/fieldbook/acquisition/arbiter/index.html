Module arbiter 

Source
Expand description

Dual-feed packet arbitration by sequence number.

FeedArbiter tracks the next expected sequence, records sequences seen on either channel, buffers packets that arrive ahead of the expected sequence and drains them once the gap is filled.

Every retained collection is bounded by entry counts and payload bytes. State is private and exposed through read-only snapshots and metrics. Two redundant feeds reporting the same sequence with different bytes produce a conflict, not an ordinary duplicate. Every submitted packet is offered to a raw-evidence sink before arbitration can reject or deduplicate it.
