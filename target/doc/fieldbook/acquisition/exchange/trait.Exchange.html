fn identity_assertions( &self, markets: &[MarketInfo], ) -> Result<Vec<VenueInstrumentMapping>>

Persistent identity assertions for the markets this adapter discovers.

The default is empty so existing adapters compile unchanged. Overrides must derive identities from immutable venue wire keys, never from titles, slugs or output symbols (ADR-0001).

Source

fn subscribed_universe(&self, markets: Vec<MarketInfo>) -> Vec<MarketInfo>

Narrow one discovery round to the markets this collector subscribes. The default keeps every discovered market; a venue whose runtime subscribes only a configured subset overrides it so metadata, desired subscriptions, acknowledgements and coverage all describe the same universe instead of counting markets the session never requests.

fn lifecycle_session_factory(self: Arc<Self>) -> Option<Arc<dyn SessionFactory>>

Optional dedicated market-lifecycle control plane.

Venues with a separate lifecycle channel return a factory whose sessions subscribe only to that channel. The coordinator spawns collector.lifecycle_replicas workers from it; book shards never carry lifecycle subscriptions. Returns None (the default) for venues without a separate lifecycle channel, or when the lifecycle plane cannot operate (for example, missing credentials).
