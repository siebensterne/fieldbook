Generic websocket supervisor. Exchange adapters implement MarketDataSession; this module owns reconnects, heartbeats, status reporting, and command handling.

Structs§

HeartbeatRequest
The correlation a successful heartbeat send established, plus the outbound observation the worker must journal. None correlation means the venue’s mechanism carries no request nonce (application text), so the single-outstanding window is the correlation rule.
HeartbeatSpec
The complete heartbeat contract an adapter supplies for its session. Every threshold is a client policy parameter, not a venue guarantee.
HeartbeatTracker
The deterministic heartbeat state machine. No networking, tasks, logging or filesystem dependencies: monotonic instants in, transitions out, so deadline behavior is owned by logic rather than timing luck. One outstanding heartbeat at a time - the text protocols this worker serves carry no request nonce to correlate a second in-flight ping.
OutstandingHeartbeat
One sent heartbeat awaiting its acknowledgement. The correlation payload is what the venue must echo back when the mechanism supports it (native WebSocket control frames); None for a nonce-less text protocol, where the single-outstanding window is the correlation rule.
SessionFrame
A batch of normalized events decoded from one websocket payload.
