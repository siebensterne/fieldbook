Module packet 

Source
Expand description

Raw packet evidence and its mapping into the existing journal contract.

Original payload bytes and packet boundaries are preserved before decode. Journal integration uses an explicit source identity supplied by the source manifest; no identity is inferred from packet content.

The v1 journal observation cannot carry channel, packet sequence, protocol, capture location or decoder version. Those fields used to be dropped by the conversion. They now travel in a versioned EvidenceEnvelope alongside the unchanged v1 observation, bound to it by a payload digest and the source/epoch/receive-time tuple. V1 and V2 readers therefore share the same retained bytes, and no field is silently discarded.
