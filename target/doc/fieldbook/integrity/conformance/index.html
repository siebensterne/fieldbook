Module conformance 

Source
Expand description

Independent source conformance harness.

A source is certified by comparing its declaration against deterministic fixtures and actual connector output. A successful connect() is never a certification signal. Every check is explicit, fail-closed, and reported with a reason so an unmet condition cannot hide behind an ordinal status.
