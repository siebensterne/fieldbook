Module completeness 

Source
Expand description

Per-symbol feed-completeness accounting for an aligned SBE capture.

verify answers whether deltas reconstruct the next snapshots exactly. This report answers a question used by backtests: which symbols never became anchored, how much of the stream was captured before the first snapshot for each symbol, and whether any symbol’s book state was ever accepted without a complete baseline.

What this does not establish:

  • that the venue delivered every event (a checksum-valid capture can still be missing events the exchange dropped upstream);
  • that observed receive buffers had no holes (reordering between sources and across sockets is visible only through sequence evidence, which is what the journal and verify record);
  • causation for silent intervals. Long quiet gaps are reported as observations with their bounds, not as missing data.

A capture is valid when no delta arrives before the symbol’s first snapshot. Unanchored deltas are itemized per symbol in CompletenessSummary::worst_unanchored (bounded sample), and the full per-symbol table is available with --include-symbols.
