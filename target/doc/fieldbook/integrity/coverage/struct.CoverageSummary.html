Expand description

Machine-readable coverage certificate for one capture.

Fields§

§schema_version: u32§capture: String§metadata: String§report: String§expected: usize

Symbols the metadata sidecar says this run selected.

§acknowledged: usize

Expected symbols with a successfully applied subscription request.

§anchored: usize

Expected symbols with at least one snapshot in the capture.

§observed: usize

Distinct symbols with any snapshot or price-level update.

§valid: bool

true only when every expected symbol was acknowledged and anchored and no contradictory symbol was observed.

§expected_set_sha256: String

SHA-256 of the sorted expected symbols, newline-separated with a trailing newline. Pins the exact expected universe to the evidence.

§capture_messages: u64

SBE messages read while certifying the capture.

§report_writer_messages: u64

SBE messages the run report’s writer accepted. Must equal capture_messages; a truncated capture cannot certify as complete.

§capture_messages_match_report: bool

true when the capture decodes exactly as many messages as the run report’s writer accepted.

§missing_ack: BoundedList

Expected symbols with no successful subscription request.

§missing_anchor: BoundedList

Expected symbols with no snapshot in the capture.

§ack_not_anchored: BoundedList

Acknowledged expected symbols with no snapshot in the capture.

§ack_not_expected: BoundedList

Acknowledged symbols absent from the metadata sidecar.

§anchored_not_expected: BoundedList

Captured snapshots absent from the metadata sidecar. Retirements and symbols captured before a later discovery round appear here.

§observed_not_anchored: BoundedList

Symbols observed only in price-level updates, never in a snapshot.

§duplicate_expected: BoundedList

Normalized symbols that occur more than once in the metadata sidecar.

§unknown_ack_native: BoundedList

Acknowledged native identifiers with no metadata mapping and no exact normalized match. These cannot be attributed to an expected symbol.
