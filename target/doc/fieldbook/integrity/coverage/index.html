fieldbook::integrity

Module coverage 

Source
Expand description

Per-symbol live-coverage certification for one aligned SBE capture.

completeness answers whether deltas arrived after a baseline. This report answers the question a live-evidence claim depends on: did every symbol the run was supposed to collect get subscribed and snapshot anchored? It compares three sets and cross-checks the capture against the run report’s writer counter (a truncated capture cannot certify as complete):

  • expected: the normalized symbols in the metadata sidecar written by the collector (markets.json);
  • acknowledged: the union of each worker’s last successfully applied subscription set, mapped from native identifiers through that sidecar;
  • anchored: symbols with at least one snapshot in the capture.

The certificate is valid only when expected, acknowledged, and anchored agree for every expected symbol, with no duplicate expected entry, no acknowledged symbol outside the expected set, and a non-empty expected set.

An empty-book snapshot counts as an anchor because the SBE snapshot still names the symbol and establishes the baseline. A symbol that appears only in price-level updates is reported under observed_not_anchored and is not anchored.

Retired symbols are reported separately: a symbol that was captured before discovery removed it can appear in anchored_not_expected without invalidating the certificate, because the expected set is the final metadata and the central invariant is about that set.

§What this does not establish

  • Venue wire acknowledgement. acknowledged_symbols records that the session successfully applied and transmitted a subscription request; the snapshot anchor is the independent proof that a book baseline arrived.
  • That the venue delivered every event. Checksums and sequence continuity belong to verify and the raw-frame journal.
  • That a periodic snapshot was generated from exchange state rather than synthesized locally. The collector only emits generated snapshots for a book that already accepted an exchange snapshot, so generated captures still imply a prior exchange anchor.
