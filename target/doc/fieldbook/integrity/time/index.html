Module time 

Source
Expand description

Timestamp conversion helpers.

Every serialized timestamp comes from the wall clock (now_us): an exchange frame’s receive time is read when the frame arrives, and a generated snapshot is stamped when it is produced, so one timeline reaches the output file. Durations, retries, and timeouts use monotonic timers (Instant/Tokio) instead; they are never serialized. Replay feeds fixture timestamps through the same paths so the core stays deterministic.
