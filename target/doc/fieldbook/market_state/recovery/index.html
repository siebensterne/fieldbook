Typed recovery decisions (M3.1).

Recovery policy is a pure function of observed conditions. A cause is evidence, not an instruction: the policy decides which action, if any, a cause authorizes. Keeping this decision separate from the collector state machine makes every recovery choice explainable and independently testable, and prevents a quiet instrument from being silently escalated into a source-wide reconnect.
