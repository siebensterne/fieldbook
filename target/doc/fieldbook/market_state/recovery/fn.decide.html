pub fn decide(signals: RecoverySignals) -> RecoveryDecision
Expand description

Decide the recovery action for one target from observed conditions.

The function is pure: identical signals always produce an identical decision. A quiet instrument, a snapshot timeout, and a scheduled refresh authorize an in-place refresh only. Transport, heartbeat, decode, protocol, and operator causes authorize a source reconnect. When both classes are present the stronger action wins, but every cause is retained. Exhausting the attempt budget records RecoveryCause::RecoveryExhausted and withholds the action instead of escalating without limit.
