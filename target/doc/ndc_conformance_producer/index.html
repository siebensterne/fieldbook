Conformance producer for the ratified canonical NDC v2 Profile 1 wire schema. This executable consumes an abstract, non-market JSON spec and writes a complete release: manifest.json, signature.json and artifacts/. It exercises the production builder, not a separate wire writer. The same ndc_release::build_release boundary validates, signs and publishes every release in this repository; the only conformance-specific inputs are the abstract spec, a test-only key seed and an isolated ledger directory.

The fixed test-only Ed25519 seed is bound to CONFORMANCE_SIGNING_SEED. The seed is a published conformance vector, not a production key. No key material is written into the release package. No provider contact, collection, right, dataset acceptance or live route is involved; a successful run proves only that the production builder mapped the abstract spec to the canonical wire shape.
